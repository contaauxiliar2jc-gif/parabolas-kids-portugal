# Parábolas Kids Portugal

Crie uma nova app web baseada visual e funcionalmente no site de referência http://parabolas-biblicas.lovable.app/, adaptada ao mercado de Portugal. O produto chama-se “1001 Parábolas Kids”. Reproduza fielmente a estrutura, estética, páginas, secções e comportamento do site de referência, substituindo toda a marca e copy conforme necessário. Na secção de preços, tenha exatamente dois planos em euros: (1) “395 Parábolas Kids” por 4,90 €/mês, com apenas 1 bónus incluído e todos os restantes bónus apresentados mas riscados a vermelho; (2) “1001 Parábolas Kids” Premium por 7,90 €/mês, com todos os bónus listados e incluídos. Use português de Portugal em toda a interface e copy, valores com vírgula decimal, e apresente claramente a comparação/benefícios dos planos. Faça uma implementação completa e responsiva.
